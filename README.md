# Vague — an Omarchy theme
Inspired from the [vague](https://github.com/vague-theme/vague.nvim) theme in neovim and uses same color palette.
I just love the plain and simple feel that It has on my eyes.

## Installation 
```
omarchy-theme-install https://github.com/ManogyaDahal/vague-omarchy
```

## How to use
- To add wallpaper just drop onto background directory and reapply theme.
